# PM2 — Основные команды

PM2 — это менеджер процессов для Node.js-приложений, который позволяет легко запускать, останавливать, перезапускать и мониторить приложения.

## Установка PM2

```bash
npm install -g pm2
```

## Основные команды

### Запуск приложения

```bash
pm2 start <путь_к_файлу> [--name <имя>]
```

Запустить приложение. Можно указать имя процесса.

### Список процессов

```bash
pm2 list
```

Показать все запущенные процессы.

### Перезапуск процесса

```bash
pm2 restart <имя_процесса_или_id>
pm2 restart all
```

Перезапустить один или все процессы.

### Остановка процесса

```bash
pm2 stop <имя_процесса_или_id>
pm2 stop all
```

Остановить один или все процессы.

### Удаление процесса

```bash
pm2 delete <имя_процесса_или_id>
pm2 delete all
```

Удалить один или все процессы из списка pm2.

### Просмотр логов

```bash
pm2 logs [имя_процесса_или_id]
```

Показать логи процесса (или всех процессов).

### Мониторинг процессов

```bash
pm2 monit
```

Открыть мониторинг в реальном времени.

### Сохранение текущего списка процессов

```bash
pm2 save
```

Сохранить текущие процессы для автозапуска после перезагрузки.

### Восстановление процессов после перезагрузки

```bash
pm2 resurrect
```

Восстановить процессы из последнего сохранения.

### Автозапуск при старте системы

```bash
pm2 startup
```

Сгенерировать команду для автозапуска pm2 при старте ОС.

### Обновление pm2

```bash
pm2 update
```

Обновить pm2 и перезапустить все процессы.

### Информация о pm2 и системе

```bash
pm2 info <имя_процесса_или_id>
```

Показать подробную информацию о процессе.
